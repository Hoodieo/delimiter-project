  <h1>Delimiter Project</h1>

  <h2>Tujuan</h2>
  <p>
    <strong>Tujuan:</strong> untuk memudahkan pengguna yang mengupdate laporan berbasis text 
    yang sering kali menggunakan delimiter berupa simbol 
    (<em> ; </em>) (<em> / </em>) (<em> . </em>) ( spasi ) (<em> tab </em>) dan lainnya.
  </p>

  <h2>Cara Penggunaan</h2>
  <p>
    Pengguna menyalinkan pesan text ke dalam <strong>input box</strong>, lalu pilih delimiter kemudian klik 
    <strong>Generate Table</strong>.
  </p>
  <p>
    Setelah tabel muncul, pilih centang pada <strong>Checklist Ignore</strong> (opsional), 
    kemudian lakukan perubahan isi yang diperlukan dengan <em>fitur-fitur yang didukung</em>, yakni:
  </p>
  <ul>
    <li><strong>Aritmatika dasar</strong>: Penjumlahan ( + ), Pengurangan ( - ), Pembagian ( : ), Perkalian ( * )</li>
    <li>Proses perhitungan dilakukan apabila angka diapit dengan simbol kurung siku <code>[ .. ]</code></li>
    <li>Perhitungan dapat dilakukan tanpa batas dan mendukung kombinasi aritmatika dasar, misalnya: <code>[ a + b + c * d : e + f ]</code></li>
    <li><strong>Vsum[]</strong> pada cell kosong untuk menghitung total secara vertikal (kolom)</li>
    <li><strong>Vavg[]</strong> pada cell kosong untuk menghitung rata-rata secara vertikal (kolom)</li>
    <li><strong>Hsum[]</strong> pada cell kosong untuk menghitung total secara horizontal (baris)</li>
    <li><strong>Havg[]</strong> pada cell kosong untuk menghitung rata-rata secara horizontal (baris)</li>
    <li><strong>Checklist Ignore</strong> untuk mengabaikan baris yang tidak ingin dilakukan perubahan apapun</li>
  </ul>
